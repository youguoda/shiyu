# 拾语 Shiyu

[![CI](https://github.com/youguoda/shiyu/actions/workflows/ci.yml/badge.svg)](https://github.com/youguoda/shiyu/actions/workflows/ci.yml)

拾语是一个 Windows 11 托盘常驻的剪贴板历史与翻译工具：安静记下你复制过的一切，
在你需要的时候把眼前的外语变成中文。

## 它能做什么

- **剪贴板历史**：每一次复制都入册——文本、链接、文件路径、HTML/RTF 富文本、
  图片（缩略图永久保留，原图按保留期清理，默认 30 天）、文件与文件夹，并记录来源
  应用与时间。可搜索、按类型/日期/子类型筛选，支持收藏、置顶、标签、分组、备注
  与使用次数。
- **三个取用入口**：光标旁的**快速条**（键盘选、回车粘贴即消失）、约 360px 宽的
  **常驻窄条**（卡片列表、就地键帽、数字键粘贴、Esc 逐层退出），以及托盘打开的
  **管理窗口**（完整搜索、筛选、批量操作）。
- **翻译**：复制外语后光标旁浮现小徽标，点击才展开面板；也可用划词/剪贴板热键
  触发。译文流式逐字呈现，英文单词附词典卡（音标/词性/释义/例句），支持逐句
  对照、朗读、方向切换，译文可一键存入历史并关联原文。
- **本地优先**：历史只保存在本机；密码管理器默认不记录；全部数据可备份导出，
  备份文件可加口令加密。

运行后拾语驻留系统托盘：左键托盘图标打开管理窗口，右键是菜单（设置、检查更新、
退出）。首次启动有一段每步都可跳过的引导。

想了解界面的方向，可以打开 [`docs/review/mockups/`](docs/review/mockups/) 里的
目标样稿（窄条/翻译面板/设置窗/管理窗）。**注意：那是设计目标稿，全部使用占位
数据，不是当前界面。**

## 隐私

- 剪贴板历史**只保存在本机** `%LOCALAPPDATA%\Shiyu`，不上传、不同步。若把数据
  位置改到同步目录（OneDrive、坚果云等），拾语会明确警告。
- **只有被翻译的那段文本**会发送给你选择的翻译方式：**免费引擎**把它发给微软必应
  翻译的网页接口（不可用时改发腾讯交互翻译，无需账号；这是网页接口而非正式 API，
  可能随时变更或限流），**自备密钥**则直接发给你配置的服务商。公共翻译通道（经拾语
  的中转服务）尚未开放；开放后被翻译的文本会经中转发给上游模型服务。剪贴板历史本身
  始终不出机器。
- 常见密码管理器（KeePass、Bitwarden、1Password 等 11 个）**默认不记录**，并遵守
  Windows 剪贴板的"排除标记"；你还可以按来源应用或内容正则添加排除规则。
- **没有遥测**，没有任何统计上报。
- "检查更新"会访问 GitHub API（`api.github.com`）；自动检查可在设置中关闭。
- 英文单词的词典卡会访问免费词典服务 `dictionaryapi.dev`。
- 翻译服务的 API 密钥保存在本机的设置文件中。
- 历史库本身**不加密**，安全性依赖 Windows 账户隔离（设计取舍见
  [ADR-0007](docs/adr/0007-history-entry-and-data-safety.md)）。请勿把数据目录放进
  会被同步或备份到别处的位置。

## 系统要求

- Windows 11（在 Windows 10 上未做验收，不承诺可用）。
- .NET 9 桌面运行时；自行构建则需要 .NET SDK 9（WPF 项目只能在 Windows 上构建）。

## 安装

从 [Releases](https://github.com/youguoda/shiyu/releases) 下载最新的
`shiyu-win-x64.zip`，校验（可选，同目录附 `.sha256` 与 `.sig` 签名）后解压到
一个固定位置（例如 `%LOCALAPPDATA%\Programs\Shiyu`），运行其中的
`Shiyu.App.exe`。

- 包为 self-contained，无需另装 .NET 运行时。
- 拾语默认开机自启，自启项指向你实际运行的位置——换了位置后从新位置运行一次，
  自启就会跟着过去。
- 应用内"设置 → 关于 → 检查更新"可检查新版本；已装 rc1 的用户会收到 0.9.0 的
  自动更新提示。

自行构建：

```powershell
dotnet build Shiyu.sln -c Release
```

产物在 `src/Shiyu.App/bin/Release/net9.0-windows/`。**调试构建**启动时不写自启，
适合开发时使用。

## 首次配置翻译

翻译有两种方式（托盘右键 → 设置 → **翻译** → 翻译方式）：

- **免费引擎**：无需账号和密钥，装好就能翻译。被翻译的文本发给微软必应翻译的网页
  接口，不可用时自动改发腾讯交互翻译。这是网页接口而非正式 API，可能随时变更或
  限流；单次最多翻译 5000 字。首次引导的翻译屏默认预选它；还没配置时，翻译面板上也有
  一键「用免费引擎」。
- **自备密钥**：使用你自己的 **OpenAI 兼容**模型服务——填写**服务地址**（可从预设里选
  一家，有免费的）、**模型**名称和 **API 密钥**。更好的质量与 AI 动作（总结、改写、
  批量翻译、LLM 词典）需要自备密钥。

不配置翻译服务时，剪贴板历史的一切功能不受影响。面向所有人的公共翻译通道
（经拾语的中转服务）仍未开放。

## 默认快捷键

全局热键（均可在设置中修改）：

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Shift+B` | 唤出 / 隐藏常驻窄条 |
| `Ctrl+Shift+V` | 快速条（光标旁，回车粘贴即消失） |
| `Ctrl+Shift+Z` | 划词翻译（翻译当前选中的文本） |
| `Ctrl+Shift+X` | 翻译当前剪贴板内容（过滤器误判时的逃生口） |
| `Win+V`（可选） | 接管系统剪贴板面板来唤起窄条，默认关闭；关闭或退出拾语自动还原 |

窄条内（**按住 `Ctrl`，每个可用动作的原地键帽就会显示出来**）：

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` | 选择条目 |
| `Enter` | 粘贴选中的条目到原来的窗口 |
| `1`–`9`、`0` | 直接粘贴第 1–10 条（置顶条目排在最前） |
| 按住 `Space` | 预览选中条目的完整内容，松开关闭 |
| `C` / `O` / `P` / `S` | 复制 / 打开 / 置顶 / 收藏 |
| `N` / `G` / `D` / `Z` | 备注 / 分组 / 删除 / 撤销删除（5 秒窗口内） |
| `←` / `→` | 切换内容类型（全部 / 文本 / 图片 / 文件） |
| `Tab` | 切换标签筛选 |
| `Ctrl+F` | 聚焦搜索框（唤出窄条后直接输入即是搜索） |
| `Esc` | 逐层退出：先关菜单与预览，再依次清掉搜索词与各级筛选，全清后才隐藏窄条 |

翻译面板内：`Esc` 关闭面板；顶部可切换翻译方向；支持复制译文、存入历史、逐句
对照与朗读。

另有一个默认关闭的**划词徽章模式**（设置 → 快捷键 → 拖选后出翻译徽标）：在任意
应用里拖选文字后，光标旁浮现"译"徽标，点击即翻译，无需记快捷键。

## 开发

```
src/Shiyu.Core          # 纯逻辑层（含 SQLite 存储），全部单元测试的对象
src/Shiyu.Windows       # 平台层：Win32 / WPF 交互（剪贴板、热键、托盘、钩子、语音）
src/Shiyu.App           # WPF 界面层（窄条、管理窗、设置、引导、更新、备份）
tests/Shiyu.Core.Tests  # xUnit 单元测试
server/                 # 公共翻译通道：Cloudflare Worker（TypeScript + vitest）
docs/                   # ADR、评审报告、人工验收清单
.scratch/               # 票（issue tracker）：shiyu-v1 / shiyu-v2 两个里程碑
spikes/                 # 技术验证样例
```

构建与测试（与 [CI](.github/workflows/ci.yml) 相同的命令）：

```powershell
dotnet restore Shiyu.sln
dotnet build Shiyu.sln -c Release --no-restore
dotnet test tests/Shiyu.Core.Tests/Shiyu.Core.Tests.csproj -c Release --no-build

cd server
npm ci
npm run typecheck
npm test
```
