# 拾语 Shiyu

[![CI](https://github.com/youguoda/shiyu/actions/workflows/ci.yml/badge.svg)](https://github.com/youguoda/shiyu/actions/workflows/ci.yml)

**简体中文** | [English](README.en.md)

Windows 11 托盘里的剪贴板历史与翻译工具。

> 筌者所以在鱼，得鱼而忘筌；言者所以在意，得意而忘言。
>
> ——《庄子·外物》

你每天要复制几十次：一句话、一个链接、一段报错、一张截图，还有半段没完全读懂的英文。可剪贴板只记得最后一次，每复制一次，就把上一次推进河里。赫拉克利特说，人不能两次踏进同一条河流；剪贴板这条河，连回头的岸都没有。

**拾语**的名字，就是它做的两件事：

- **拾**：把你复制过的每一段字句捡起来，按时间放好，要用时在光标旁一伸手就拿到；
- **语**：把眼前的外语变成你读得懂的话，也把你想说的话变成别人读得懂的语言。

古人以「道不拾遗」称颂太平。在剪贴板这条路上，拾语偏要拾遗：只拾你自己的，也只放在你自己的电脑里。

它守着一条朴素的原则：**贪婪记录，克制打扰**。记，一条不漏；扰，能免则免。老子说「凿户牖以为室，当其无，有室之用」：屋子能住人，是因为中间是空的。拾语大多数时候都不在你眼前：窄条贴完即收，翻译面板从不抢走你的光标，「译」徽标默认不弹。它的用处，恰恰在这份「无」里。

## 三十秒上手

1. 从 [Releases](https://github.com/youguoda/shiyu/releases/latest) 下载 `shiyu-win-x64-setup.exe` 安装。托盘里会出现拾语的图标（Windows 11 可能先把它收进任务栏右侧的「^」里），首次启动有一段每步都能跳过的引导。
2. 随手复制几样东西，然后在任意输入框里按 **`Win+Alt+V`**：窄条出现在光标旁，`↑` `↓` 选，`Enter` 贴回。
3. 选中一段外文，按 **`Win+Alt+Z`**：译文在旁边逐字流出来。默认的免费引擎不用注册，也不用填密钥。
4. 在聊天框里按 **`Win+Alt+Q`**：打中文，出英文，`Enter` 贴回去。

## 由浅入深

从什么都不用设置的一层，到要接上大模型的一层，一层一层往下挖。

### 第一层 · 记：一次复制都不放过

> 无为而无不为。——《老子》

你什么都不用做。拾语在托盘里守着剪贴板，每复制一次就记一条：

- 文本、链接、文件路径、带格式的 HTML / RTF 文本、图片、文件与文件夹，都收；
- 每条记下来源应用和时间；图片的缩略图永久保留，原图默认保留 30 天；
- 断了网、不配翻译，记录照常：这一层不依赖任何服务。

不记什么，和记什么一样重要：

- KeePass、Bitwarden、1Password 等 11 个常见密码管理器，默认不记；
- 复制方在剪贴板里标了「勿记录」，拾语照办；
- 你还可以按来源应用，或用 `re:` 开头的正则按内容，加上自己的排除规则。

常驻也要轻：打开「轻量模式」，窄条隐藏后就释放界面资源、压缩常驻内存，期间照常记录。

### 第二层 · 取：快的窄条，全的历史窗口

记下来，是为了取得回来。拾语给了两个入口，一快一全，各管一摊。

**窄条**（`Win+Alt+V`）管每天几十次的快取：

- 出现在输入光标旁，直接打字就是搜索，`↑` `↓` 选，`Enter` 贴回原来的窗口；
- `1`–`9`、`0` 直接贴第 1–10 条，置顶的排在最前；
- 按住 `Space` 预览全文；按住 `Ctrl`，每个动作的键帽就浮出来；
- 鼠标停在卡片上，动作托盘随之出现：复制、粘贴、纯文本粘贴、打开、定位、置顶、收藏、备注、归组、删除。要哪几个、按什么顺序，在设置里定；
- `Esc` 逐层退出；贴完即收，点右上角的图钉就**常驻钉住**；
- 习惯了 `Win+V` 的手，可以让 `Win+V` 也呼出它（默认关，退出拾语自动还给系统）。

**历史窗口**（托盘右键「历史…」、窄条上的品牌钮，或你给它设的热键）管慢慢翻的全集：完整搜索，按类型、日期、子类型筛选，收藏、置顶、标签、分组、备注、使用次数，批量操作。收藏与置顶的条目受**删除保护**：不参与自动清理，也不会被批量删掉。

### 第三层 · 懂：把外语变成你的话

> 我的语言的界限，意味着我的世界的界限。——维特根斯坦《逻辑哲学论》

三条路通向翻译面板，各有各的时机：

| 入口 | 什么时候用 |
| --- | --- |
| 划词翻译 `Win+Alt+Z` | 读到看不懂的，选中就译 |
| 翻译剪贴板 `Win+Alt+X` | 已经复制了；或者徽标「该弹没弹」，用它坚持一下 |
| 「译」徽标（默认关） | 打开后，复制外语时光标旁浮出「译」，点一下才翻；还能让拖选文字后也浮出 |

翻译面板：

- 译文流式逐字出现；面板**从不抢焦点**，你在原来应用里选中的文字不会丢；
- 单个英文单词附**词典卡**：中文释义、音标、考试标签（中考到 GRE），还能听读音。约 4.2 万个常用词内置在本机，断网也能立即查到，查 went 会给出 go；能联网时再补上英文例句。没收的生僻词照旧在线查；
- 能切「逐句」对照，能朗读，能一键换方向；
- 选中的是中文、译文语言也是中文时，拾语认出这是「回声」，自动掉头译成英文；
- 有用的译文点「存入历史」，与原文关联着收进剪贴板历史；
- 每一次翻译都进「翻译记录」，在历史窗口的「翻译记录」页能查回来（默认 30 天自动清空）。

### 第四层 · 说：把你的话送出去

> 辞达而已矣。——《论语·卫灵公》

读懂是向内，写出是向外。**反向输入框**（`Win+Alt+Q`）在当前输入框旁呼出：

- 打中文，手一停，英文就出来；按 `Enter` 或点底栏的 `↵`，贴回原处；
- `Tab` 换方向，`Shift+Enter` 换行；输入法正在选字时，`Enter` 归输入法；
- 贴完会把你原来的剪贴板还回去（打开「自动复制译文」时则留下译文）：它只是个运输工。

**提示词模板**决定这段文字被怎样处理，面板与反向输入框通用（接上自备密钥的大模型才生效）：

- **标准 / 口语 / 正式**：翻译，换个语气；
- **提示词优化**：把随手写下的需求，整理成给 AI 编程助手的提示词；
- **自建模板**：写下你自己的 prompt，润色、改成邮件、译成文言文，随你。

模板在框里点一下就能换，`Ctrl+E` 循环切换。改写类模板按 `Enter` 才开始整理，整理完先停下给你过目，再按一次才贴。

### 第五层 · 思：请模型替你整理（需自备密钥）

> 学而不思则罔，思而不学则殆。——《论语·为政》

接上你自己的大模型，历史窗口里选中的条目可以：

- **总结**、**改写**；
- **合并成笔记**：多选几条，就是一个收集篮；
- **建议标签**：建议出来的标签，点一下就加上；
- **批量翻译**。

中文单词也能查到词典卡，由模型生成。

这一层有条铁律：**没有任何后台的、自动的、逐条的模型处理**。你不点，它不发。

### 第六层 · 守：边界就是信任

> 莫见乎隐，莫显乎微，故君子慎其独也。——《中庸》

没人看着的时候，才见一个工具的品性。

- **剪贴板历史只在本机**（`%LOCALAPPDATA%\Shiyu`），不上传、不同步。把数据位置改到 OneDrive、坚果云这类同步目录时，拾语会明确警告：历史库本身不加密，安全靠的是 Windows 账户隔离（取舍见 [ADR-0007](docs/adr/0007-history-entry-and-data-safety.md)）。
- **只有你要翻译的那段文字会离开电脑**，发给你选的翻译方式：免费引擎发给微软必应翻译的网页接口，不可用时改发腾讯交互翻译（无需账号；这是网页接口而非正式 API，可能随时变更或限流）；自备密钥则直接发给你配置的服务商。
- **没有遥测**，没有任何统计上报。除了翻译，只有两处会联网：「检查更新」访问 GitHub API（`api.github.com`，自动检查可以关）；英文单词的词典卡会访问 `dictionaryapi.dev`（内置词典查到时只为补例句，没查到时查释义）。
- **凭据各归其主**：自备密钥按服务商各存一份，只发给它所属的那一家；在设置文件里由 Windows 加密保护，备份默认不带。
- **备份**可以加口令加密；导入时可以选合并或覆盖。
- **更新包带签名**：安装前用内置的公钥校验，对不上就不装。

## 几种思维

老子说「有无相生，难易相成」。拾语里也有几对看似相反的想法，各管一件事，合起来才是它：

| 一对思维 | 在拾语里的样子 | 管的是什么 |
| --- | --- | --- |
| **贪婪 ↔ 克制** | 记录一条不漏；打扰能免则免：徽标默认关，面板不抢焦点，窄条贴完即收 | 你不必判断「这条值不值得留」，也不会被它打断 |
| **被动 ↔ 主动** | 看不懂的（外→中）走划词、徽标；要写出去的（中→外）走反向输入框 | 读与写，各有一条最短的路 |
| **快 ↔ 全** | 窄条：一列卡片，键盘几下取用；历史窗口：筛选、标签、批量 | 快的不臃肿，全的不仓促 |
| **确定 ↔ 生成** | 判断值不值得弹徽标，用规则，不用模型；免费引擎零配置；模型只在你接上、并且点下时才出场 | 简单的事用确定的办法，复杂的事才请模型 |
| **在场 ↔ 退场** | 窄条要键盘，所以拿焦点，贴完立刻还你；面板只给你看，所以从不拿焦点 | 出现时恰好够用，用完不留痕迹 |
| **记得 ↔ 忘记** | 缩略图永久，原图到期清理；翻译记录按周期清空；有些东西从一开始就不记 | 记住该记的，忘掉该忘的 |

## 组合技

单个功能是招式，连起来才是套路。

### 读

- **查词三连**：选中生词 → `Win+Alt+Z` → 看词典卡、听读音 → 把头部的模板换成「口语」，看看日常里怎么说（自备密钥）。
- **啃长文**：选中一段 → `Win+Alt+Z` → 切到「逐句」对照着读 → 有用的点「存入历史」，以后在窄条里一搜就到，「翻译记录」里也查得到。
- **中文直出英文**：选中一段中文 → `Win+Alt+Z`。译文语言是中文时，拾语认出这是回声，自动掉头译成英文。

### 写

- **回外国同事的消息**：在聊天框里 `Win+Alt+Q` → 打中文 → 模板换成「口语」→ `Enter` 贴回（自备密钥）。再打开「自动复制译文」，译文还会收进历史，下次直接从窄条里拿。
- **把需求讲给 AI**：`Win+Alt+Q` → 模板换成「提示词优化」→ 随手写下中文需求 → `Enter` 整理 → 过目 → 再按 `Enter`（或点 `↵`）贴进 AI 编程助手的对话框（自备密钥）。

### 整理

- **收集篮**：白天随手复制，晚上在历史窗口里多选相关的几条 →「合并成笔记」→ 复制结果拿去用；再对它们「建议标签」，点一下就归档（自备密钥）。
- **找回上周那句译文**：历史窗口 →「翻译记录」页 → 搜原文或译文，单击一条，原地展开全文。

### 顺手

- **素材板**：写长文时点窄条右上角的图钉把它钉住，常用的几条置顶；要用时按 `Win+Alt+V` 再按 `1`–`9`，贴完窄条还在原地。
- **换掉 Win+V**：设置 → 快捷键 → 打开「也用 Win+V 呼出」，老习惯不用改；退出拾语，`Win+V` 自动还给系统。
- **搬家**：设置 → 常规 → 备份，加口令导出；在新电脑上导入，选合并或覆盖。

## 手册

### 安装

从 [Releases](https://github.com/youguoda/shiyu/releases) 下载最新的安装包 `shiyu-win-x64-setup.exe`，双击运行：

- 只为当前用户安装，不需要管理员权限；默认装在 `%LOCALAPPDATA%\Programs\Shiyu`，可以在安装时换一个位置（新的或空的文件夹）。
- 可以勾选在桌面创建快捷方式；开始菜单里总会有「拾语」。
- 拾语正在运行时，安装和卸载会请你先从托盘退出它。
- 卸载在 Windows「设置 → 应用」里。卸载时会问要不要同时删除历史记录、翻译记录和设置，默认保留，以后重新安装还能接着用。
- 安装包没有代码签名，Windows 可能提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。想核对下载的文件，同目录附 `.sha256` 与 `.sig` 签名。

也可以用免安装的 `shiyu-win-x64.zip`：校验后解压到一个固定位置（例如 `%LOCALAPPDATA%\Programs\Shiyu`），运行其中的 `Shiyu.App.exe`。原来用 zip 的，直接运行安装包并装到原来的文件夹即可，历史记录与设置不受影响。

- 两种方式都自带 .NET 运行时，无需另装。
- 拾语默认开机自启，自启项指向你实际运行的位置：换了位置后从新位置运行一次，自启就会跟着过去。
- 托盘图标：左键打开设置，右键是菜单（历史、暂停记录、检查更新、退出等）；拾语已在运行时再启动一次，同样打开设置。
- 「设置 → 关于 → 检查更新」可检查新版本，安装版与免安装版都能原地更新。

### 首次配置翻译

翻译有两种方式（托盘右键 → 设置 → **翻译** → 翻译方式）：

- **免费引擎**：无需账号和密钥，装好就能翻译。被翻译的文本发给微软必应翻译的网页接口，不可用时自动改发腾讯交互翻译。这是网页接口而非正式 API，可能随时变更或限流；单次最多翻译 5000 字。首次引导的翻译屏默认预选它；还没配置时，翻译面板上也有一键「用免费引擎」。
- **自备密钥**：使用你自己的 **OpenAI 兼容**模型服务：填写**服务地址**（可从预设里选一家，有免费的；预设带「申请密钥」直达与「测试连接」）、**模型**名称和 **API 密钥**。提示词模板、AI 动作（总结、合并成笔记、改写、建议标签）、批量翻译与中文词典卡都需要自备密钥。

不配置翻译服务时，剪贴板历史的一切功能不受影响。

### 快捷键

全局热键（都可以在 设置 → 快捷键 里改）：

| 快捷键 | 作用 |
| --- | --- |
| `Win+Alt+V` | 快速粘贴：在输入光标旁呼出窄条；贴完即收，钉住后常驻 |
| `Win+Alt+Z` | 划词翻译：翻译当前选中的文字 |
| `Win+Alt+X` | 翻译剪贴板：过滤器误判时的逃生口 |
| `Win+Alt+Q` | 反向输入框：在当前输入框旁打中文、出英文 |
| （默认不设） | 打开历史 |
| `Win+V`（可选） | 也用 Win+V 呼出窄条，默认关；关掉或退出拾语即还给系统 |

这些组合键在拾语运行期间归拾语，会盖掉其他应用里的同名快捷键。默认的一组用 `Win+Alt` 开头，避开了编辑器、浏览器、聊天软件、Office 的常用键；在设置里录到常见冲突时会就地提醒。0.16.1 及以前装的拾语保留原来的 `Ctrl+Shift+Z`（很多应用里的「重做」）、`Ctrl+Shift+V`（「粘贴为纯文本」）、`Ctrl+Shift+X` 与 `Alt+Q`（Microsoft 365 的「跳到搜索框」）——想换成新的一组，在 设置 → 快捷键 点「恢复全部默认」。

窄条内（**按住 `Ctrl`，每个可用动作的原地键帽就会显示出来**）：

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` | 选择条目 |
| `Enter` | 粘贴选中的条目到原来的窗口 |
| `1`–`9`、`0` | 直接粘贴第 1–10 条（置顶条目排在最前） |
| 按住 `Space` | 预览选中条目的完整内容，松开关闭 |
| `C` / `O` / `P` / `S` | 复制 / 打开 / 置顶 / 收藏 |
| `N` / `G` / `D` / `Z` | 备注 / 分组 / 删除 / 撤销删除（5 秒窗口内） |
| `←` / `→` | 切换内容类型（全部 / 文本 / 图片 / 文件） |
| `Tab` | 切换标签筛选 |
| `Ctrl+F` | 聚焦搜索框（唤出窄条后直接输入即是搜索） |
| `Esc` | 逐层退出：先关菜单与预览，再依次清掉搜索词与各级筛选，全清后才隐藏窄条 |

反向输入框内：

| 按键 | 作用 |
| --- | --- |
| `Enter` / 点 `↵` | 往前走一步：出结果，或贴回原处 |
| `Shift+Enter` | 换行 |
| `Tab` | 换方向（改写类模板：换输出语言） |
| `Ctrl+E` | 换提示词模板 |
| `Esc` | 关闭，不贴 |

翻译面板内：`Esc` 关闭；头部可以换方向、换模板；底部可以复制译文、存入历史、朗读，也能切逐句对照。

## 结语

**拾与舍**

柏拉图在《斐德若》里讲过一个故事。文字的发明者图提把文字献给埃及王塔姆斯，说它能让人更聪明、记性更好。国王却说：恰恰相反，有了文字，人们会把记忆交给身外的符号，自己反倒健忘；你发明的不是记忆的药，只是提醒的药。

拾语就是一剂「提醒的药」。它替你记住复制过的一切，于是你可以放心地忘；它替你翻译，于是你不查词典也能读完一段外文。这是解放，还是依赖？

博尔赫斯写过一个什么都忘不掉的人，富内斯。他记得每一片叶子、每一朵云的形状，却再也无法思考，因为「思考就是忘记差异，就是概括，就是抽象」。完美的记忆不是智慧，是负担。所以拾语也在学着忘：原图到期清理，翻译记录按周期清空，密码从一开始就不让它记。拾与舍并不相反：舍掉该舍的，拾起的才找得到、用得上。

海德格尔说，一把称手的锤子，用的时候是「隐身」的：你眼里只有钉子，没有锤子；只有锤子坏了，它才重新出现在你面前。拾语想做的就是这样一把锤子：窄条贴完即收，面板不夺光标，徽标默认不扰。它最好的状态，是你几乎忘了它在。

可一个让人忘记它的工具，会不会也悄悄让人忘了别的东西：那个本该自己记住的词，那句本该自己推敲的英文？所以面板里留着词典卡、读音和逐句对照：它不只替你翻，也愿意陪你学。走到哪一步，由你决定。

庄子说完「得意而忘言」，紧接着叹了一句：

> 吾安得夫忘言之人而与之言哉！
>
> ——我到哪里去找一个忘了言语的人，和他说说话呢？

这句话自相矛盾：要和忘言的人交谈，仍然得用言语。工具与人大概也是这样：借它记住，为的是不必记住；借它翻译，为的是终有一天不必翻译。拾语拾起的是言语，留给你的，是言语之外的那一点意思。
