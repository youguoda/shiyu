# ADR-0012：v3 界面与交互决策

- 状态：已接受（#12 已被 ADR-0013 修订，2026-10-04）
- 日期：2026-10-01
- 依据：`docs/review/2026-10-01-ui-design.md` §7.3（用户全部采纳）
- 修订：票 30 / 33 的"窗口圆角 12"；排版 2 的档位（2026-10-09，加「特大」22 并落地为设置）

## 背景

2026-10-01 的 UI 评审结论是"骨架对，表层粗"：底层的令牌、动效计划、对比度测试是 7 分水平，
表层执行是 3 分水平。评审列出了七个共性根因和一组需要拍板的产品决定。本 ADR 记录这些决定，
作为 v3 界面工作的约束。

## 决策

### 排版
1. **控件文字回到 Fluent 的 14**（`Type.Body` 14/20）：按钮、标签、输入值、导航都用它。
2. **内容字号默认 18/31**（被阅读的剪贴板正文、译文），可在设置里调为 16 / 18 / 20。
   2026-10-09 落地为设置「内容字号」（常规 → 外观）：用户在"整体缩放"与"只调内容字号"
   之间选了后者，并加一档「特大」22，档位为 16 / 18 / 20 / 22。随它变的是窄条卡片正文、
   预览、翻译面板的译文与词头、反向输入框；反向输入框是光标旁的小浮层，用低一档的紧凑
   内容字号（标准档 16/28）。每档的字号与行高见 `ContentRamp`。
3. "再大一号"的诉求以后只走两条路：内容字号设置，以及跟随系统"辅助功能 › 文本大小"。
   **不再整体上调控件字号令牌**（两天内四次上调已经造成按钮相撞）。
4. 中文一律 Regular；SemiBold 只给拉丁词头、键帽、分组标题；任何开关和选中态都不得只靠
   字重表达；斜体只给拉丁文本。

### 形状与外壳
5. **圆角两档**：`Radius.Control` 4（按钮、输入、列表行、设置卡、**窄条卡片**、键帽）；
   `Radius.Overlay` 8（所有窗口和浮层外壳，交给 DWM 画）。胶囊的圆角按"高度的一半"推导。
   废除 `Radius.Window` 12 和 `Radius.Pill` 13。这推翻了票 30 / 33 的"窗口 12"：12 与 DWM 的 8
   不同心，像素上能看到两条弧。
6. 每个窗口只有一套轮廓：边框和阴影交给 DWM，WPF 不再在外壳上画 `DropShadowEffect`。
7. 常规窗（管理窗、设置窗）改走系统窗框；Mica 用非分层窗口的配方实现，先做 spike 验证，
   不行就用 Mica 的官方回退色（#F3F3F3 / #202020）。

### 交互
8. **快速条并入窄条**：只保留"窄条"一个名词，两个呼出意图——
   - 快速粘贴（Ctrl+Shift+V，可选"也用 Win+V"）：粘贴后消失，失焦即消失；
   - 打开窄条（Ctrl+Shift+B）：常驻，用来翻看、整理、预览。

   前提：开启轻量模式时，窄条冷呼出的 P95 不比快速条慢 100 ms 以上。达不到就保留快速条作为
   "快速粘贴"的轻量实现，但对用户只呈现一个概念，并共用窄条的组件。
9. **双击 = 粘贴**（窄条与快速条统一）；窄条里的"复制"由托盘按钮和 C 键承担。
10. **"只看收藏" = Alt+S**，与托盘上"收藏当前卡"的 S 区分。
11. **单词态的朗读读原词**：发音钮放在词头旁，语种取源语言；句子态仍读译文。
12. **首次引导的翻译方式默认"自备密钥"**（见 ADR-0009）。→ 已被 ADR-0013 修订：默认"免费引擎"。
13. 浮层里不放实心 accent 主按钮：静止态只有一处 accent，就是当前选中项。
14. 用户发起的关闭一律瞬隐；只有系统发起的离场（例如徽标超时）才淡出。
15. 设置窗**即改即生效**，去掉"保存 / 关闭"底栏；只有数据位置、导入备份、自备密钥三类保留显式操作。

## 后果

- 按钮、标签会比现在看起来小一档，而被阅读的内容不变或更大。
- 票 30 / 33 中与圆角、材质有关的实现要按本 ADR 改写；它们的目标（Win11 观感）不变。
- 详细规格见 UI 评审报告 §4（设计系统）与 §6（目标设计）。
