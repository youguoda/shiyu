# ADR-0009：翻译通道 v1 采用"自备密钥优先"，公共中转推迟上线

- 状态：已接受（决策 1 已被 ADR-0013 修订：首次引导改为默认"免费引擎"，2026-10-04）
- 日期：2026-10-01
- 修订：票 36（公共翻译通道）中"引导：公共通道列为默认路径"一条

## 背景

票 36 实现了公共中转（`server/` 下的 Cloudflare Worker）和客户端的 `RelayBackend`，
首次引导对没配过密钥的用户预选公共通道。2026-10-01 的评审发现这条默认路径必然失败：

1. 端点 `https://shiyu-relay.workers.dev` 从未部署，而且是占位形态——Workers 的默认域名
   是"脚本名.账号子域.workers.dev"。
2. `*.workers.dev` 在中国大陆整域被 DNS 污染（2026-10-01 实测：本地解析与 AliDNS 都返回
   Facebook / Twitter 的地址段，TLS 握手失败）。即使部署了，大陆用户也连不上。
3. 服务端在上线前还有必修的安全问题（语言字段注入、全局额度可被耗尽、IPv6 未聚合、
   额度计数非原子、盐缺失时回退默认值）。

公共中转不是一个功能，而是一项**运营承诺**：要付模型调用费，要防滥用，要保证大陆可达。
这些都不是写完代码就能满足的。

## 决策

1. **v1 的首次引导默认"自备密钥"**：预设几家国内可直连、兼容 OpenAI 接口的服务商
   （选中即填好服务地址和模型），提供"测试连接"，允许"稍后配置"。
2. **公共通道在满足上线条件之前不出现在可选项里**（或显示为"即将推出"，不可选）。
   上线条件：
   - 绑定自定义域名，并在大陆网络实测可达；
   - 服务端加固完成（v3 票 05）；
   - 有人愿意承担模型调用费用和日常运营。
3. 服务端代码保留并继续加固，等待上线条件满足。
4. 需要通用对话能力的功能（管理窗的 Agent 动作）只在配置了自备密钥时可用，
   否则禁用并说明原因，而不是运行时失败。

## 后果

- 新用户需要自己申请一个 API 密钥。这是真实的门槛，用"服务商预设 + 申请链接 + 测试连接"
  把它降到最低。
- 历史记录的隐私边界不变：被翻译的那段文本发给用户自己选择的服务商。
- 票 36 的"二期默认化另行开票"仍然成立；本 ADR 只是把一期的默认路径也收回来了。

## 回头选项

上线条件满足、并有真实用户的使用数据之后，重新评估是否把公共通道设为默认。

（2026-10-04 补注：首次引导的默认路径已由 ADR-0013 改为免费引擎。本回头选项改为：
免费引擎失效且无法修复时再议。）
