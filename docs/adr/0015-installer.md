# ADR-0015：安装包（Inno Setup，只为当前用户安装）

- 状态：已接受
- 日期：2026-10-12
- 依据：用户需求 2026-10-11——"配置成一个安装包，从 GitHub 下载之后点击安装，可以选择装在哪里"；
  用户 2026-10-12 拍板：只为我安装；跳过引导不放进安装器；卸载时询问是否删数据；暂不考虑
  代码签名证书；安装时可以选要不要在桌面建快捷方式

## 背景

拾语只发一个 zip：下载、校验、解压到一个固定位置、运行。对多数人来说，"解压到哪里、以后怎么卸"
都是要自己琢磨的事，开始菜单里也没有它。

拾语自己的几样安排决定了安装包能怎么做：

- **应用内更新原地换文件**（ADR-0010）：在数据目录里暂存新版，再由暂存的那一份以普通权限把
  安装目录里的文件换掉。装进 `C:\Program Files` 这类要管理员才能写的地方，更新就永远换不进去。
- **数据不在程序目录里**：历史、图片、设置在 `%LOCALAPPDATA%\Shiyu`（或用户挪去的「数据位置」）。
- **开机自启是拾语自己写的**：当前用户 Run 键里的 `Shiyu`，指向正在运行的那一份 exe。
- **单实例**：托盘常驻，互斥量 `Local\Shiyu`。

## 决策

1. **Inno Setup 6.7，产物 `shiyu-win-x64-setup.exe`，与 zip 并排发布。** zip 留给想解压即用的人，
   也仍是应用内更新下载的那一份。MSIX 不能选安装位置还必须签名；WiX/MSI 对个人项目太重；Velopack
   会顶掉我们带签名校验的更新。构建机上的 Inno Setup 版本钉死（`tools/installer/install-inno.ps1`，
   下载按 SHA-256 核对、便携解包，不往系统里装）。
2. **只为当前用户安装。** `PrivilegesRequired=lowest`，默认 `%LOCALAPPDATA%\Programs\Shiyu`，可以改，
   不弹管理员确认，不提供"为所有用户安装"——应用内更新因此照常可用。升级沿用上次的位置。
3. **只许装进新的、空的或原来的拾语文件夹。** 卸载会删掉整个安装文件夹（应用内更新可能带来安装时
   没有的文件），所以选目录那一页拒绝放着别的东西的文件夹。原来用 zip、解压在默认位置的用户，
   安装包直接接管那个文件夹。
4. **快捷方式**：开始菜单总有「拾语」；桌面快捷方式是安装时的一个勾选项，默认不勾。
5. **跳过引导不放进安装器。** 引导首屏已有「跳过，用默认设置」，Esc 也能跳过；升级、重装的用户
   本来就不会再看到引导。
6. **卸载**：拾语开着就先请用户退出（AppMutex）；删掉指向本安装目录的开机自启（别处的拾语不碰）；
   问一句要不要同时删除数据，默认「否」，静默卸载也是「否」。删数据交给拾语自己
   （`Shiyu.App.exe --remove-user-data`，规则在 Core 的 `UserDataRemoval`）：默认位置整个删；挪去的
   「数据位置」是用户选的文件夹，只删拾语认得的文件（历史库、按拾语命名的图片与日志、更新暂存、
   提示记录），空了才连文件夹一起删；拾语还开着就一样不删。
7. **「应用和功能」里的版本号跟着应用内更新走。** 拾语启动时若发现自己就是卸载项记的那一份
   （`{AppId}_is1` 的 InstallLocation），把 DisplayVersion 改成自己的版本（Shiyu.Windows
   `InstallRegistration`）。AppId `{158C0196-252A-4126-8516-DC9C05C0B7BB}` 永远不改。
8. **暂不签名。** 下载的安装包会被 SmartScreen 拦一下（"Windows 已保护你的电脑"），README 写明怎么
   放行。ADR-0010 的签名只防自动更新被篡改，管不到这个提示；要根本解决得买代码签名证书，另议。
9. **每次推送都真装真卸一遍。** CI 的 installer job 与发布流水线走同一组脚本：发布 self-contained、
   编译安装包、静默装进临时目录、核对文件/卸载项/版本号/快捷方式、试"连数据一起删"与清自启、
   静默卸载、核对清干净。本机冒烟不做删数据与改自启（那是用户自己的），由脚本拦着。
10. **Windows 10 先说清楚，不拦。**（2026-10-16，功能评审 F-13 · D6）build 号小于 22000 时，安装
    开始前弹一句「拾语还没有在 Windows 10 上验收过……仍要继续安装吗？」，默认「是」；静默安装照装，
    只在日志里留一行。冒烟用 `/SMOKEWINBUILD=19045` 在任何机器上走这条分支，核对日志里有这一行、
    安装照常完成。`MinVersion` 仍是 10.0。

## 后果

- Releases 多三个文件（安装包、它的 `.sha256` 与 `.sig`）；安装包约 45 MB，比 zip 小（LZMA2）。
- 没有签名，首次运行安装包时有 SmartScreen 提示；装好之后再启动就没有了。
- 卸载删的是安装文件夹整个；用户若手动往里面放了别的东西，会一起删掉——选目录时已拦住了绝大多数
  这种情况。
- 数据挪到别处又在那里放了无关文件的用户，卸载后那个文件夹会留下（只删拾语认得的），这是有意的。
