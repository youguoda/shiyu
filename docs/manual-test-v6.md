# 拾语人工验收清单（v6 · 0.9.1 之后的迭代）

> 0.9.1 正式版之后的功能迭代合进 master 后，必须由人眼、人手判断的项收在这里，按票分组；
> 机器可测部分由单元测试与探针覆盖。票在合入时把自己的一节补进来。
>
> 准备：日常用的拾语即可。翻译项需要一个自备密钥：设置 → 翻译 → 服务商预设 → 粘贴密钥 →
> 保存凭据。
