# 无障碍与手动走查清单（调研报告 §5/§8 的一次性核对）

- 适用版本：0.18.2+；执行环境记录在案（显示器/DPI/系统版本/输入法）后再逐项过。
- 每项：步骤 → 期望。发现偏差记 qa-findings。

1. 200% DPI：全窗口走查（窄条/预览/面板/反向框/历史/设置）——布局不破、文字不裁。
2. 高对比度模式：开高对比度 → 各窗口核对可读性。
3. 讲述人（Narrator）：逐窗口 Tab 顺序与控件名抽查。
4. 纯键盘：设置窗全页 Tab 顺序可达；历史窗全操作纯键盘可达。
5. 减少动效开 → 所有动画一步到位（贴边滑动、预览淡出、滑动动画）。
6. 中文 IME 激活：热键与全局钩子在 IME 组字中仍响应。
7. 多屏混合 DPI：窄条拖到副屏、预览跨屏、锚点不飘。
8. 第三方剪贴板管理器共存：与 Ditto 同开时的顺序与争用。
