# 02 — 反向输入框贴回纯文本；面板可复制纯文本

**来源：** 评审 F-02（已知问题挂了 4 版）
**Status:** ready-for-human

**What to build:** `MarkdownText` 加「渲染为可粘贴的纯文本」：标题去井号、强调去星号、列表 "- " / "1. "、表格按行 Tab 分隔、代码块保留原文、链接留文字（与网址）。反向输入框 Enter 贴回默认用纯文本；面板「复制」按住 Shift 复制纯文本（或菜单）。原文仍进翻译记录。

**验收：** 「提示词优化」的结果贴进记事本不含 `*`、`#`、三个反引号；面板复制仍能拿到 Markdown 原文。
