# 26 — 预览弹窗的钉住与干净模式

**来源：** 用户需求 2026-10-19
**Status:** ready-for-human

**What to build:** 悬停预览加一枚图钉；钉住时预览不随移开/收起消失，一直在屏幕最上，且元信息与键帽提示收起、只留干净的预览内容。

**验收：** 悬停出预览 → 点钉 → 提示与元信息消失、只剩内容 → 鼠标移开、窄条收起，预览仍在最上 → 再点钉 → 收起、恢复悬停规则；钉着时删除那张卡片 → 预览自动收起。

## Comments

- 2026-10-19 实现：
  - 预览窗元信息行右侧一枚图钉（空心/实心随状态，Focusable=False——预览从不抢焦点）。
  - 钉只挡自动收起：`TakeDown` 的三个调用点（窄条隐藏、策略时机、策略 Esc）全被钳住；悬停其他卡片不再夺走内容（钉住的独占）。结构性例外：宿主窄条关闭（预览不能比宿主活得久，历史实录的缺陷类）与钉着的那张卡片被删除（幽灵预览）时强制收起。
  - 干净模式随钉：元信息行与教学行收起，只留正文；同卡刷新路径也保持（`&& !Pinned`）。取消钉即收起。
  - probe-preview-pin（已进 run-all）：钉住、干净模式、收起被拒、取消钉收场——1 项 PASS。
- **待你实机验收**：悬停出预览 → 点钉 → 提示与元信息消失 → 移开鼠标、收起窄条 → 预览仍在最上；再点钉 → 收起。

## 工作台扩展（2026-10-20，用户需求：钉住后文字可改、图片可放大 + 相应设置）

- **钉住 = 会话式窗口化**：钉住那一刻摘掉预览窗的「永不激活」（TransientWindow.MakeActivatable），WM_MOUSEACTIVATE 钩子放行——点击与打字进得来；取消钉/收起即恢复原样。未钉的每次显示都把 NOACTIVATE 摆回去（同一句柄跨显示复用，不能带着可激活的样子复活）。
- **文字条目**：正文区换编辑框（点进去即编，Esc 退出编辑留在只读展示）。改动是草稿不碰原条目；动作行「复制」带走、「存为新条目」进历史顶部。
- **图片条目**：滚轮缩放（朝光标）、放大后拖拽平移、双击复位（1–8×）。窗内裁剪，不改解码与存储。
- **动作行按形态出芯片**（替换教学行的同一槽位）：文本/译文「复制·存为新条目」；链接「打开·复制·存为新条目」（OpenUrl）；邮箱「写邮件·复制·存为新条目」（mailto）；路径「打开·定位·复制」；文件「打开·定位·复制路径」；图片「复制图片」（原图字节 PNG+DIB）；颜色「复制色值」。全部复用条上现成实现（OpenUrl、FileEntries.Alive 解析、写入器 SetImage）。
- **设置**：不新增设置页条目——图钉本身就是开关（设置克制原则：开关须对应两类互斥真实用户）；「记住钉住状态跨会话」v1 不做，等真实反馈。
- probe-preview-pin 断言：钉住、干净模式、收起被拒、取消钉收场——PASS。待加：文字改后「存为新条目」进历史、图片缩放的手感。
