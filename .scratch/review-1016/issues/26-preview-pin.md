# 26 — 预览弹窗的钉住与干净模式

**来源：** 用户需求 2026-10-19
**Status:** ready-for-human

**What to build:** 悬停预览加一枚图钉；钉住时预览不随移开/收起消失，一直在屏幕最上，且元信息与键帽提示收起、只留干净的预览内容。

**验收：** 悬停出预览 → 点钉 → 提示与元信息消失、只剩内容 → 鼠标移开、窄条收起，预览仍在最上 → 再点钉 → 收起、恢复悬停规则；钉着时删除那张卡片 → 预览自动收起。

## Comments

- 2026-10-19 实现：
  - 预览窗元信息行右侧一枚图钉（空心/实心随状态，Focusable=False——预览从不抢焦点）。
  - 钉只挡自动收起：`TakeDown` 的三个调用点（窄条隐藏、策略时机、策略 Esc）全被钳住；悬停其他卡片不再夺走内容（钉住的独占）。结构性例外：宿主窄条关闭（预览不能比宿主活得久，历史实录的缺陷类）与钉着的那张卡片被删除（幽灵预览）时强制收起。
  - 干净模式随钉：元信息行与教学行收起，只留正文；同卡刷新路径也保持（`&& !Pinned`）。取消钉即收起。
  - probe-preview-pin（已进 run-all）：钉住、干净模式、收起被拒、取消钉收场——1 项 PASS。
- **待你实机验收**：悬停出预览 → 点钉 → 提示与元信息消失 → 移开鼠标、收起窄条 → 预览仍在最上；再点钉 → 收起。
