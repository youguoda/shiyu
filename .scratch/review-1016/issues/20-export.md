# 20 — 导出 CSV / Markdown

**来源：** 评审 F-19
**Status:** ready-for-human

**What to build:** 历史与翻译记录可导出 CSV / Markdown；支持只导出选中。图片条目导出占位与文件名，不导出二进制。

**验收：** 选中 3 条导出 CSV / Markdown，内容与条目一致。

## Comments

- 2026-10-16 实现：
  - 入口：历史窗口「⋯」→「导出…」；翻译记录页命令栏右侧「导出…」（在「清空全部」左边）。有选中先问「选中的 N 条 / 全部」，再选文件与格式。
  - Core `EntryExport` / `TranslationLogExport` 边读边写（`EntryExport.All` 按游标一页页读，不一次装进内存）。
    - CSV：带 BOM 的 UTF-8，RFC 4180 引号；以 = + - @ 打头的格子补 `'`（防表格软件当公式执行）。
    - Markdown：每条一节，正文包在比内容里最长反引号串还长的围栏里。
    - 图片：「[图片 宽×高] 原图文件名」，原图已清理的如实说；文件条目导出路径。
  - 写文件先写 .partial 再换上，失败不留半个文件；后台线程写，结果一句话落在窗口的轻提示里。
  - 11 个测试。
- **待你实机验收**：历史里选 3 条 →「⋯」→「导出…」→「选中的 3 条」→ 存成 CSV 用 Excel 打开、再存一份 Markdown 看一眼；翻译记录页同样试一次。
