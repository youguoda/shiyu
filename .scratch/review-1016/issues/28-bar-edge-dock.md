# 28 — 窄条的贴边隐藏

**来源：** 用户需求 2026-10-20
**Status:** ready-for-human

**What to build:** 常驻钉住的窄条可缩进屏幕顶缘只露细条；鼠标靠近顶缘展开、离开收回；全屏应用在前台时不打扰；拖动窄条视为改位置、贴边自动关闭。

**验收：** 开贴边 → 呼出用完收起 → 窄条只剩顶缘细条 → 鼠标进细条展开 → 移开收回 → 全屏视频时不打扰 → 拖动后贴边自动关。

## Comments

- 2026-10-20 实现：
  - 设置：设置 → 窄条 →「贴边隐藏」（常驻钉住的子项，隐含钉住；关钉住时一并关；开贴边时自动开钉住）。
  - 隐藏形态：窗口上移到只露 3 DIP 细条贴在工作区顶缘（Windows 任务栏自动隐藏的同款形态）；展开 = 完整落回工作区顶。移动走物理像素 MoveTo（混合 DPI 同款）。
  - 展开的闸：FullScreenOverlay.IsForeground()——全屏应用在前台时鼠标扫过顶缘不打扰。
  - 收回时机：鼠标离窗即收回细条；预览还开着时等它收（钉住的预览独立于窄条存活，互不抢）。
  - 拖动窄条 = 改位置：贴边自动关闭（设置跟着走）；EdgeDockWanted 事件由窄条 Module 写设置。
  - 粘贴/召唤：召唤时展开在光标旁，用完收回贴边（Dismiss 的贴边分支不隐藏、回到细条）。
  - probe-bar-dock（已进 run-all）：收回只露 3 DIP、进窗展开到工作区顶、离窗收回、关贴边还原——4 项断言。
