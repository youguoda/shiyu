# 14 — 管理窗多选「粘贴全部」

**来源：** 评审 F-12
**Status:** ready-for-human

**What to build:** 管理窗多选后「粘贴全部」：按选中顺序、换行分隔，贴回打开管理窗前的那个窗口。

**验收：** 选 3 条按顺序贴出 3 行。

## Comments

- 2026-10-16 实现：
  - 历史窗口多选后「粘贴全部」：详情栏多选面板「整理」组第一个按钮，窄窗口没有详情栏时用「⋯」菜单第一行。
  - 选中先后由 Core `SelectionOrder` 跟着 SelectionChanged 记（列表控件的 SelectedItems 在范围选、全选、重载后按列表顺序重排，靠不住；重建列表补回选中的那几拍不记）。
  - 贴出的文字由 `BatchPaste.Join` 拼：一条一行，多行条目保持原样；文件贴路径，图片跳过并报数。
  - 贴回目标：每次呼出历史窗口时记下前台窗口（拾语自己的窗口不算，沿用上次）。托盘入口改为等菜单收起一拍再开（同快速粘贴），窄条品牌钮把它记着的那扇窗传进来。
  - 回不去（不知道是哪扇 / 管理员窗口 / 抢不回前台）就只复制并说清楚；贴成功后各条使用次数 +1。
  - 9 个测试。
- **待你实机验收**（会动真剪贴板）：在记事本里按历史窗口的快捷键（或托盘「历史…」）→ Ctrl+点选 3 条（故意不按列表顺序）→「粘贴全部」→ 记事本里按点选的先后出现 3 行。
