# 08 — 生词本

**来源：** 评审 F-09
**Status:** ready-for-human

**What to build:** 词典卡加星标（收进生词本）；翻译记录页加「生词」筛选；导出 CSV（Anki 可导入：词头、音标、释义、原句）。数据在 translation_log 加一列。

**验收：** 收藏 3 个词后在「翻译记录 → 生词」看到 3 条；导出的 CSV 含词头、音标、释义、原句。

## Comments

- 2026-10-16 实现：
  - 数据：`translation_log` 加一列 `vocabulary`（JSON：词头、音标、释义、例句、考试标签——收词那一刻的卡）。表结构 15 → 16，按列在不在决定加不加：旧版拾语打开过新库会把 user_version 改回 15，再回新版不能因"列已存在"起不来（有测试）。
  - 面板：词典卡头加 ☆（卡到了才露面），空心点下收、实心点下移出。收的是这个原文最近的一条翻译记录；没有（翻译记录关着、还没译完）就专为它记一条。排除名单照样拦。
  - 历史窗口「翻译记录」页：命令栏加「生词」开关，只看收下的词，行首标「★ 生词」；开着时「导出…」走 `VocabularyExport`：CSV 带 Anki 文件头（`#separator:Comma` / `#html:false` / `#columns:词头,音标,释义,例句,标签`），同一个词只导出最新一次；也可导 Markdown。
  - 生词不随翻译记录的到期清理走；「清空全部」也留着它们（确认框写明留下几条）。
  - **与验收的出入**：「原句」拾语拿不到——取词只拿到选中的那个词，拿不到它所在的句子。导出的第四列叫「例句」，取自词典卡（在线词典补到的例句）。若票 09 的 UIA 取词能拿到所在句，再补真正的原句。
  - 测试 12 个；探针 probe-panel-dictionary 加了 flow:vocabulary-star（点星 → 星变实心、生词本里正好是这个词），PASS。
- **待你实机验收**：查 3 个英文词各点一下 ☆ → 历史窗口「翻译记录」→「生词」看到 3 条 →「导出…」存 CSV → Anki「导入」能直接认出各列。
