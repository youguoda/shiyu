# 18 — AI 动作的结果可以存为条目

**来源：** 评审 F-17
**Status:** ready-for-human

**What to build:** 动作结果旁加「存为条目」：存成一条新记录，备注里关联来源条目。

**验收：** 合并成笔记后存为条目，历史里多一条，备注写着来源。

## Comments

- 2026-10-16 实现：
  - 历史窗口 AI 结果面板加「存为条目」：总结 / 合并成笔记 / 改写才有，建议标签没有；结果完整译完才点得动，存一次后变「已存为条目」。
  - Core `ClipboardPipeline.RecordActionResult` 过排除闸口后 Append + SetNote。
  - 备注由 `AgentActions.ResultNote` 生成，例：「由「合并成笔记」生成，来自 3 条：「周一的会议纪要：预算还差…」「…」「…」」。最多点名 3 条、每条 12 字，其余写「等」。来源应用记作 Shiyu，与收下的译文一样。
  - 5 个测试。
- **待你实机验收**：历史窗口多选 2–3 条 →「合并成笔记」→ 跑完点「存为条目」→ 列表顶上多一条，备注写着来源。
