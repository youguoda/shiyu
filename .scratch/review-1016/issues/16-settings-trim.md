# 16 — 设置瘦身：立规则，低频项收进「更多」

**来源：** 评审 F-15
**Status:** ready-for-human

**What to build:** CONTEXT 里写规则：开关必须对应两类互斥的真实用户，否则选默认值。设置页把低频项（文本行数、图片高度、文件条数、悬停预览延迟、完成提示音、来源图标等）收进可折叠的「更多」；搜索与深链照常能找到。不删任何设置。

**验收：** 各页首屏只有常用项；搜索低频项能直接定位并展开。
