# 14 — UI 线程减负：图片解码、文件探测、常驻轮询

**来源：** 优化报告 O-36、O-37；审计 A2 §3.2、§4.5
**Blocked by:** 12
**Status:** done（0.9.0 验收轮通过后发布；验收记录见文末）

**What to build:**
- 卡片先出占位，缩略图与原图在后台线程解码，`Freeze` 后交给 UI；剪贴板图片只在 UI 线程取原始字节，解码与指纹挪到后台。
- 文件存在性探测改为后台批量加缓存（路径在离线网络盘上时，现在每次唤出窄条都要等 SMB 超时）。
- 从窄条粘贴后隐藏时，走完整的 `Dismiss` 流程：现在计时器不停，也不进入轻量模式。
- 预览计时器按需触发；系统主题改为监听 `WM_SETTINGCHANGE`，不再每 5 秒轮询。

**验收：**
- [ ] 窄条里有离线 UNC 路径的条目时，唤出耗时 < 200 ms
- [ ] 窄条隐藏时，进程每秒唤醒次数接近 0（Process Explorer 观察）
- [ ] 复制一张 4K 截图时 UI 无可感知卡顿
